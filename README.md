A program that writes one funny patch-note line (93 characters) for a bug in real life: the mouth's autopilot reply — answering "you too" when the waiter says "enjoy your meal", as if the waiter were about to sit down and eat it as well.

## Run it

```sh
node main.ts
```

This writes the patch note to `/output/entry.txt`.
